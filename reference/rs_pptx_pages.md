# Several scenes as the slides of one PowerPoint file.

Several scenes as the slides of one PowerPoint file.

## Usage

``` r
rs_pptx_pages(scenes, outline_text, title)
```

## Arguments

- scenes:

  A list of compiled scenes.

- outline_text:

  Write text as glyph outlines.

- title:

  The presentation title (empty: the first scene's).

## Value

A list of `bytes` and `warnings`.
