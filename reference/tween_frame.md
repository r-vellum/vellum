# The tweened scene of one frame between keyframes `a` and `b` at fraction `frac` (one curve for every class), for inspecting a mid-transition frame (`$element_table()`, `$pixel()`) without rendering a whole animation.

The tweened scene of one frame between keyframes `a` and `b` at fraction
`frac` (one curve for every class), for inspecting a mid-transition
frame (`$element_table()`, `$pixel()`) without rendering a whole
animation.

## Usage

``` r
tween_frame(a, b, frac)
```
