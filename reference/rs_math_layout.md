# Lay out a formula. Returns the glyph and rule arrays (points, y up, baseline 0) and the extents, or `list(message, position)` on a parse error (`position` NA for a font error).

Lay out a formula. Returns the glyph and rule arrays (points, y up,
baseline 0) and the extents, or `list(message, position)` on a parse
error (`position` NA for a font error).

## Usage

``` r
rs_math_layout(src, path, face, size, display)
```
